# Security and privacy reporting

Report suspected vulnerabilities privately to **support@onekapisch.com**, with “Handlefree security” in the subject. Do not open a public issue with exploit details or personal data.

Include the affected app version, general device/vehicle model and steps to reproduce. Do not send vehicle keys, VINs, credentials or precise location. We will request additional information if needed; no response-time SLA is promised.

This showcase has no application backend and stores no vehicle data. GitHub hosts public issues under its own policies. Support messages are processed to address your request; the app's data handling and retention are described in the [privacy policy](https://handlefree.app/privacy-policy/).

No secrets or private implementation files belong in this repository. Approved public screenshots may include simulator fixture data only.
