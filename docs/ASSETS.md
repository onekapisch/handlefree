# Approved public assets

- assets/icon.png: developer-approved Handlefree app icon.
- assets/01-entry.png, 02-controls.png, 03-no-app.png, 04-privacy.png: the English App Store screenshots of Handlefree 1.0 (Studio v3 set), unchanged.
- assets/de/01-entry.png to 04-privacy.png: the German App Store screenshots of the same set, unchanged.
- assets/handlefree-banner.png: generated for the public showcase and GitHub profile using the profile renderer at onekapisch/onekapisch, scripts/build-bento.mjs (tile-handlefree). It composes the approved icon and transparent door panel without modifying their source pixels. Since the App Store release (7 October 2026) it carries a red "New release" badge, Apple's official "Download on the App Store" badge (no Web chip: Handlefree is an iPhone app) and the tagline "Skip the handle of your Tesla. A simpler way in." instead of BETA.
- assets/appstore-badge-en.svg and appstore-badge-de.svg: Apple's official "Download on the App Store" badges (black, English and German), unchanged, as used on handlefree.app. Use them only to link to the Handlefree App Store listing, under Apple's marketing guidelines.
- assets/real-car-en.jpg and real-car-de.jpg: still frames of the real-car clip on handlefree.app (the developer's own recording: one press on the iPhone Action Button unlatches the driver door). Third-party number plates and personal details are blurred; keep them blurred in any crop.

The screenshots are 1320 × 2868 pixels and were captured in the iOS Simulator, so the "Simulator preview · No vehicle connected" line is visible. The tile is 3072 × 688 pixels. GitHub displays both at the available README width. Do not remove simulator labels from screenshots or imply official Tesla artwork.
