# Contributing feedback

This is a product showcase, not an open-source implementation. Documentation corrections and focused accessibility, setup or vehicle-entry suggestions are welcome.

Use the issue templates. Search for an existing report first. Include only what is needed to understand the problem. Keep VINs, keys, locations, account details and unredacted diagnostics out of public issues.

Do not test while driving or actuate a door/trunk when the area is obstructed. Acknowledged commands do not prove physical movement. Report security concerns privately according to SECURITY.md.

App source-code contributions are not accepted here. A public repository does not grant permission to redistribute the app, brand or artwork.
